## How to use
### Discord app

**Vencord / Vesktop**
1. Settings → Themes → **Online Themes**
2. Paste this link and save:
```
https://fdt-themes.github.io/DiscoCities/DiscoCities.theme.css
```

**BetterDiscord**
1. Download [DiscoCities.theme.css](https://raw.githubusercontent.com/fdt-themes/DiscoCities/main/DiscoCities.theme.css) (right-click → Save link as)
2. Put it in your BetterDiscord themes folder and enable it

**OpenAsar**
* Copy the text from the file above and paste it into OpenAsar's Quick CSS field

### Web browser
* [![](https://img.shields.io/badge/install%20with-stylus-006666?style=flat-square)](https://raw.githubusercontent.com/fdt-themes/DiscoCities/main/DiscoCities.user.css)

### Customize the wallpaper
The wallpaper is darkened so text stays readable. To change it, add this to your Quick CSS and change the last number (`0.6` = brighter, `0.9` = darker):
```css
:root { --fdt-wallpaper-dim: rgba(3, 3, 22, 0.8); }
```
